# C++ Data Structures

A collection of C++ programs I am using while learning data structures and algorithms.

## Current Topics

- Binary Tree
- Binary Search Tree
- AVL Tree

## Operations

Each example supports insertion, deletion, searching, inorder/preorder/postorder/level-order traversals, height, node and leaf counts, and minimum/maximum lookup.

- The Binary Tree inserts in level order and deletes by replacing the target with the deepest, rightmost node.
- The BST keeps values ordered and ignores duplicates.
- The AVL Tree keeps values ordered, ignores duplicates, and rebalances after insertion and deletion.
